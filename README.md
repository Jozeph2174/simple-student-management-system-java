# Student Management System (Java Desktop Application)

A simple Java-based desktop application built using **Java Swing** and **MySQL**.  
The system allows users to register students and store their details in a database.

## 🚀 Features
- Java Swing GUI
- Add student records
- MySQL database integration (JDBC)
- Clean project structure (DAO, Model, UI)
- Offline desktop application

## 🛠 Technologies Used
- Java (JDK 17)
- Java Swing
- MySQL
- JDBC (MySQL Connector/J)
- NetBeans IDE
- XAMPP
